
# League of Legends Esports News AI

An AI-powered League of Legends esports news
platform developed as an AI engineering
learning project.

## Project Goals

- Collect esports news from permitted sources.
- Analyze news using AI.
- Generate source-backed content.
- Review content before publishing.
- Manage media permissions.
- Process authorized esports videos.
- Publish approved content through Meta Graph API.

## Technology Stack

- Python
- FastAPI
- SQLite
- Streamlit
- Groq
- GPT-OSS 120B
- FFmpeg
- Meta Graph API
